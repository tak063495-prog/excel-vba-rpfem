## 1. 動作環境と入手

- 通常の解析はWindowsのデスクトップ版Microsoft Excelで行います。VBA、Windows API、Scripting.Dictionaryなどを使う実装です。Excel for the web、Google Sheets、LibreOfficeをこの版の実行環境として扱いません。Macや32bit環境の受入れは今回確認していません。大きいモデルは64bit Excelを使用することを勧めます。
- 完成XLSMだけで通常の解析を実行できます。Pythonは独立検証用で、実行時の必須依存ではありません。
- 空のブックに3つの改訂モジュールだけを取り込んでも動きません。配布XLSMの全プロジェクトと入力シートを使います。
- マクロの通常実行には「VBAプロジェクトオブジェクトモデルへのアクセスを信頼する」の許可は不要です。自動コード反映・コンパイル検証用のCOMスクリプトとは区別します。

## 2. まずP06Nを実行する

1. コピーをExcelで開き、「P06N 実行案内」を読みます。配布版はP06Nの入力済み・全解析未実行の状態です。
2. 「材料データ」を確認します。初期値は次の3材料です。弱層のc=0は意図した設定で、便宜的な正の値へ置き換えません。

|行|材料ID|c [kPa]|φ [度]|γ [kN/m³]|ψ [度]|
|---|---:|---:|---:|---:|---:|
|5|1|20|35|19|0|
|6|2|0|25|19|0|
|7|3|10|35|19|0|

3. 「設定」でMODE=Fs、ANALYSIS_POLICY=DAVIS_EQUIVALENTと、後述のG1R12設定を確認します。
4. 「要素定義」の**「要素作成②」**を押し、**「図を表示」**で外形・材料境界・拘束・メッシュを確認します。この操作は形状の事前確認です。
5. **「解析」**を押します。解析は入力からメッシュを再生成して上下界と適応処理を行います。事前の要素作成結果をそのまま固定して求解する操作ではありません。
6. 終了後、「解析結果」とログ末尾を確認し、計算後のブックを別名で保存します。比較用に入力、設定、ログ、計算済みXLSMを一緒に残します。

|ボタン|対応マクロ|役割|
|---|---|---|
|要素作成②|RPX_CreateMesh|入力検査・メッシュ生成。Fsの求解は行わない|
|解析|RPX_Run|入力から解析し、上下界・結果・場を出力|
|図を表示|RPX_ShowDiagram|図シートへ移動。入力変更後は再生成した図を確認|
|中止|RPX_Stop|中止フラグを立てる。イベント処理・確認点で停止|

ボタンを使えない場合は`Alt+F8`から、対象ブックの上記マクロを選択します。**通常操作でRPX_Setupを実行しないでください。** このマクロは入力シート・図形を初期化し、標準斜面の入力を書き込むため、P06Nや編集済みモデルを消します。

計算は長時間になる場合があります。解析中は入力を変更せず、別のケースのマクロを重ねて起動しません。中止は即時割込みとは限らず、長い因子分解の途中では次の確認点まで待つ場合があります。

## 3. 別のモデルを作る

P06Nのコピーで入力を編集します。表に古い材料・領域・面条件を残したまま新ケースを継ぎ足すと、意図しない領域や荷重が残るため、使わない入力行も整理します。式を含む入力は、解析開始時の再計算後の値で検査されます。

### 要素定義シート

入力は7行目以降、6行目が見出しです。

|列|入力|意味|
|---|---|---|
|A:C|点ID、X、Y|座標[m]。点IDは正の整数で重複しない|
|E:H|領域ID、材料ID、剛体ID、境界点ID|境界点IDを多角形の周囲順にカンマ区切りで記入。土の剛体IDは0|
|J:P|面ID、領域ID、開始点、終了点、循環、拘束、剛体ID|領域境界の定義順をたどる経路を指定|
|Q:R|固定Fx、固定Fy|荷重倍率によらない面荷重[kPa]|
|S:T|比例Fx、比例Fy|極限荷重倍率を掛ける基準面荷重[kPa]|

面条件は開始点と終了点を直線で結ぶ指定ではなく、領域の境界順をたどり、途中の点・折れ曲がりを含みます。末尾から先頭をまたぐ場合は循環=1とします。境界順、共有点、多層の境界を図で確認してください。

拘束は「自由」「固定XY」「固定X」「固定Y」「剛体」です。「固定X」はX方向の速度を拘束し、Y方向を自由にします。「固定Y」はその逆です。面の剛体IDは拘束が「剛体」の場合に指定します。荷重成分は全体座標系のX/Yです。Y上向きを正に取るモデルでは下向き荷重は負です。

### 材料データシート

4行目が見出し、5行目以降が入力です。

|列|入力|範囲・意味|
|---|---|---|
|A|材料ID|正の整数、領域の材料IDと対応|
|B|c [kPa]|0以上。0と小さい正の値は異なる材料モデル|
|C|φ [度]|0以上89未満|
|D|γ [kN/m³]|0以上。自重の体積力に使用|
|E|ψ [度]|0以上φ以下。**空欄はφとして読み込むため、ψ=0なら0を明記**|
|F:H|剛体ID、中心X、中心Y|剛体の中心[m]|
|I:K|X固定、Y固定、回転固定|1=固定、0=自由|
|L:N|固定Fx、Fy、M|剛体の固定外力・モーメント、単位奥行き当たり|
|O:Q|比例Fx、Fy、M|剛体の基準外力・モーメント、単位奥行き当たり|

2次元・単位奥行きの単位系で、剛体の並進荷重はkN/m、モーメントはkN·m/mです。面荷重[kPa]と合力[kN/m]を混同しません。使わない荷重成分にも0を入力します。

層ごとに材料IDと領域を対応させれば多層を扱えます。材料が違う内部辺は、この実装の上界で速度連続のbondとして扱われます。独立した摩擦接触の入力ではありません。[界面の注意事項](NOTES_JA.md#4-多層と剛体界面)

## 4. 解析設定

値はB列、キーはD列にあります。D列は通常非表示です。設定はキーで読み込むため、別版では行番号よりキーを優先します。

|配布版セル|キー|初期値|意味|
|---|---|---|---|
|B4|MODE|Fs|Fs / 極限支持力|
|B5|TARGET|1536|目標要素数。初期生成数と必ず一致する値ではない|
|B6|GRAVITY|固定|極限支持力での自重の扱い。Fsでは実荷重を維持|
|B7|ADAPT|1|適応メッシュを実行。0では固定メッシュの経路|
|B8|CYCLES|3|既存適応サイクルの上限|
|B9|GAP|0.01|上下界差/中点の目標。0.01=1%|
|B10|REFINE|0.2|局所細分化率。既存経路の設定|
|B11|QUADRATURE|8|上界散逸・内部辺条件の細分数。入力範囲1–16|
|B12|FS_TOL|0.0001|Fs根の探索許容差。入力範囲1e-6–0.01|
|B33|DIAGNOSTIC_MODE|1|診断ログON|
|B40|C0_AUTO|0|専用c=0候補経路。P06Nでは有効にしない|
|B41|ANALYSIS_POLICY|DAVIS_EQUIVALENT|関連 / Davis等価関連 / 旧政策を区別|
|B42|RAW_LOWER_AUDIT|1|元単位の下界監査を有効にする|
|B44|HSD_SOLVE_SECONDS|3600|1回のHSD求解の時間予算。全解析の上限ではない|
|B48|ADAPT_MESH_POLICY|LEGACY_THEN_REFINE|従来の再配置・細分化の後に追加細分化|
|B49|ADAPT_REFINE_CAP|1000|追加段階の要素予算。TARGETとの小さい方|
|B50|FS_BRACKET_POLICY|AUDITED_UPPER_LIMIT|適格な多層モデルの下界試行位置に監査済み上界を使用|

G1R12の追加赤緑細分化は最大1回です。既存メッシュが既に上限を超えている場合に縮小する機能ではありません。新しいFs試行制御は剛体・単層を対象外とし、LEGACY_THEN_REFINEの800要素以下の前段でも無効です。B48とB50をともにLEGACYにすると、追加細分化と新しい探索制御を停止します。詳細は[実装報告](../versions/G1R12/REPORT.md)を参照してください。

P06Aを作る場合は各材料のψをφに合わせ、ANALYSIS_POLICY=ASSOCIATEDにした別コピーを使います。P06Nのψ=0・Davis等価モデルとは別の解析です。ASSOCIATEDでは計算上の低減後ψ=φになり、入力ψを独立の非関連流れ則として求解する設定ではありません。

TEST_INJECTION=0、RAW_LOWER_AUDIT=1を保持します。通常の利用でHSDやSchurの実験設定を一括変更したり、精度を合わせるために許容差を緩めたりしません。

## 5. 結果の読み方

|解析結果シート|読み方|
|---|---|
|A1|全体の終了状態。目標未達なら「上下界を取得…未達」などと表示|
|B4/C4|下界/上界。Fsモードでは強度低減安全率、支持力モードでは荷重倍率|
|B8、D8|解析政策と補足。Davis等価モデルの結果か確認|
|B9|上下界差/中点。目標GAPと比較|
|B10/C10|適応解析では下界/上界の採用要素数。別メッシュのことがある|
|B11|画面の計算時間。長時間実行の比較にはログのelapsed_sも使う|
|B12|通常のFs探索の最大最終ブラケット幅。上下界間のGAPとは別|
|B15/C15|適応解析で採用されたメッシュの由来|
|18行目以降|適応段階の履歴。求解数、メッシュ、上下界など|

目標達成は、完成したペア、監査、上下界順序、Fs探索の終了、目標GAPをまとめて判定します。個々の求解の`OPTIMAL`だけで、全解析の精度を達成したとは判断しません。`PARTIAL_CERTIFIED`は監査済み端点を得ても目標未達などが残る状態です。

「図」の赤矢印は上界の速度機構を表示長さで規準化したものです。変位・沈下量・実際のm/sを表していません。「要素データ」の上界速度も参照仕事で規準化されています。下界応力は引張正のBernstein係数で、節点の直接的な応力測定値ではありません。上下界の採用メッシュが異なる場合、要素番号で単純に重ねません。

## 6. 極限支持力モード

Fsモードのまま解析して得た安全率を、支持圧[kPa]として読み替えません。

1. 支持力モデルのコピーを作り、MODE=極限支持力を設定します。
2. 固定荷重と、倍率を掛ける比例荷重を分けます。集計する面に下向きの比例荷重が必要です。
3. BEARING_FACES（配布版B13）に、集計面IDをカンマ区切りで指定します。必要な場合だけBEARING_RIGIDS（B14）に追加集計する剛体外力のIDを指定します。同じ外力を面と剛体に二重入力しません。
4. 集計面の水平投影幅を確認します。鉛直面だけで幅が0になる設定は使えません。
5. 解析後、荷重倍率の上下界、平均極限支持圧、鉛直合力、集計幅を確認します。

平均支持圧は`(選択対象の固定鉛直合力 + λ×比例鉛直合力) / 選択面の水平投影幅`です。水平投影幅は選択された境界辺の|Δx|の合計で、曲がった接触面の実長とは異なります。任意の重なった投影を幾何学的に統合する集計ではないため、対象面の選び方を確認します。G1R12追加時の支持力全回帰は未実施です。

## 7. ログと保存

DIAGNOSTIC_MODE=1の場合、ブックと同じフォルダーの`RPFEM_logs/`へ`日時_PID_analysis.tsv`が作られます。UTF-16のタブ区切りです。ブックを保存済みで、フォルダーに書込み権限があることを確認します。ログ作成に失敗した場合は、結果シートの診断案内も確認してください。

- `run_start`：実行環境。
- `settings`、`material`など：入力条件。
- `solve_start`、`solve_end`：1回の円錐求解。
- `fs_point`、`audit`：試行Fsと原式監査。
- `adapt_action`、`adapt_staged_end`：追加メッシュ段階。
- `fs_upper_limit`、`fs_upper_limit_fallback`：新しい試行位置制御と従来探索への復帰。
- `error_origin`、`outcome`、`run_end`：停止原因と全体の判定。

詳細の切分けは[注意事項](NOTES_JA.md#8-停止した場合の確認)を参照してください。計算済みXLSMだけでなく、同じ実行のログ、入力・設定、版を保管します。

## 8. ソースを変更する場合

[反映・復元手順](../versions/G1R12/IMPORT_ROLLBACK.md)に従います。`src/`はUTF-8編集用、`import_cp932/`はCP932・CRLFのVBE取込み用です。文書モジュールを標準モジュールとして追加しません。通常の解析にtests/のProbeや試験用の代替処理を取り込みません。

Python検証は[試験手順](../versions/G1R12/TEST_PROCEDURES.md)を参照してください。G1R12の旧新比較はG1R11原本を使い、必要なら環境変数`RPFEM_BASELINE_XLSM`へ絶対パスを指定します。GitHub全体をcloneした場合は同梱の前版も探索します。過去版の全Excel試験を自動再実行する構成ではありません。
