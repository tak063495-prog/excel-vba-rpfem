## ダウンロードと再検証

[P06N専用ZIP](P06N_PYTHON_EVIDENCE_20261017.zip)を展開するか、このディレクトリを使います。Python3.13の環境で次を実行してください。Excel・DLLは不要です。

```powershell
python -m pip install -r requirements.txt
python -B -X utf8 VERIFY.py --output ../P06N_REAUDIT_NEW.json
```

出力は一式の外にある未作成JSONを指定し、その親ディレクトリは先に作成します。既存結果は上書きしません。

`VERIFY.py`は、保存された応力・速度・原dualから元q8問題を組み立て直して再監査します。新しい最適化は呼びません。材料・自重・境界は正規入力から再構築し、メッシュ／物理モデル／方針／Fs／qの対応と原SHAを照合します。古い絶対パスは明示した読取用の対応表で解決し、元JSONや元ソースのバイトを変更しません。

今回、独立展開先でもGAP1.9723805913%と両物理場の合格を再確認しました。上界反対端点の原dualもフルベクトルから再監査し、補正前のstationarity約1.7849e-7は棄却、補正後の約8.9246e-8は合格しました。cone変数zは補正前後でバイト単位に一致します。

下界の反対端点には保存されたフルベクトルがありません。その符号は当時の根履歴・同一性・幅の確認にとどまり、この再監査で独立に再生成したとは扱いません。改変したNPZを検査前に拒否する負例も確認しています。
