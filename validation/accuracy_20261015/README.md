## 方針変更

ユーザーの費用対効果の判断により、1% を狙う追加精度実験を停止した。
合格基準は対称上下界幅 2% 以下とし、高速化へ移行する。
上記の確定済み Python 保存場は両ケースとも新基準に合格する。
今回の追加実験から新しい確定上下界は採用していない。
初期状態からの VBA/DLL 本番計算で同じ精度を再現したという意味ではない。

実行中の精度用 Python ジョブは所有 PID・生成時刻・コマンドを照合して停止し、
入力・実装・既存公開証拠のハッシュが不変であることを記録した。
精度優先の Excel 本番計算も、所有する Excel だけを正常取消・終了する。
精度追加用 `ADAPT_PRECISION_FROM_START` は隔離候補・既定 0 のままとし、
速度優先設定には採用しない。

高速化では、2% 到達後の追加改善の停止、同一入力・モデル・q・メッシュに
結び付いた保存場と根区間の再利用、DLL 経路の利用を優先する。
物理監査の誤差基準を緩めて速度を得る変更はしない。

## 維持する採用条件

- 相対上下界幅は `2*(U-L)/(U+L)`、現在の目標は 0.02 以下。
- 原問題の全行と独立した物理監査を維持する。原物理残差・生応力誤差は
  1e-7 以下。下界荷重係数は 1.000001 以上、上界値は 0.999999 以下。
- 各側の根幅は `1e-4*max(1, midpoint)` 以下。同じ Fs・モデル・メッシュ・
  積分次数・方針に結び付いた証拠を要求する。
- 補助 QP の目的や変数座標は候補生成にだけ使用する。補助 QP の双対は
  原問題の根判定に使用しない。ソルバーの終了状態や相対残差だけでは採用しない。
- 失敗した候補で既存の確定ペアを置き換えない。原 full-dual helper の成功は
  その Fs・メッシュの離散探索符号の証拠に限り、独立の連続体上下界にしない。

## 今回の実験

以下は停止までに試した内容の記録。追加の 1% 精度実験は実行しない。

1. P06A: 原散逸仕事を再構成し、従来の速度勾配指標による c=0 帯への
   偏りを確認。抵抗仕事を担う粘着層を中心に、方向細分化と全粘着層の
   red refinement を比較する。元の上界場を子メッシュへ写し、元 Fs の
   原物理監査が通ることを先に確認する。
2. P06N: 元の原双対に基づく目標指標と散逸仕事を比較。単純な面積重み QP は
   原 cone/flow 残差を満たさず不採用。重み比、座標平行移動、粘着層の細分化を
   別々に検証する。
3. 下界の補助実験: 親の二次 Bernstein 応力多項式を実在する子メッシュへ
   制限し、子の降伏条件を課す。候補は子の原問題全体で検証する。
   射影・縮約後の双対は子の原問題の根判定に使用しない。
4. VBA/DLL: 最新 main のソースを隔離して組み合わせ、実際の DLL 呼び出しを
   記録する Excel 本番計算を実施する。Python 場の読み込み監査と、初期状態からの
   本番計算を区別して記録する。

各実験フォルダーに入力・実装の SHA-256、実行所有情報、原監査結果、
必要な full vectors を保存する。未完成・不採用のファイルを公開用証明として扱わない。
