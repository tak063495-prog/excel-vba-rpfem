# 後続VBA改修案：指定静水圧のメッシュ不変性

対象は指定静水圧モードで、最初の実装・検証対象はD08Aの水平水位y=3とする。これは材料・構成則・物理許容の変更ではなく、既存の指定水圧場の折れ点を解析メッシュが正確に表すための幾何修正である。現在VBA/DLLは編集していない。

1. 元の土領域の三角形分割後、解析用荷重とSOCPを組み立てる前に、指定水位を横断する三角形を分割する。水位と元の辺の交点は元の節点組のキーで共有し、境界と材料界面でT字接続や重複節点を作らない。水位上の既存節点・辺は再使用する。各子は親の材料IDを保持し、正の向き、領域面積、一次モーメント、元の境界面との対応を検査する。
2. 水位線を新しい拘束面にしない。同じ材料の内部辺として扱い、速度ジャンプや応力の面力条件は既存規則に従う。外周の分割辺は元の境界種別と荷重を受け継ぐ。D08Aには露出面の外部水圧面力がない。
3. 初期メッシュを適合させれば、既存の中点分割・内部点分割は水位横断を作らない。各生成・読込後に横断がないことを検査し、静水圧勾配を下側(0,-gamma_w)、上側(0,0)として計算する。P1節点圧力の勾配と同じ式であり、丸めによる人工水平水圧勾配を避けられる。親子で同じ体積荷重を保持できる。辺反転・再配置・再メッシュを行う経路では水位辺を幾何制約として保持し、水位を跨ぐ新しい三角形を作らない。水位辺の保護を材料ID変更や速度接着拘束で代用しない。
4. 修正後はepoch/mesh ID/荷重キャッシュを更新する。旧非適合メッシュの場や根を新メッシュにそのまま認証しない。必要なら補間を候補生成にだけ使い、原q8の新規監査とown-mesh根探索を要求する。今回Pythonは旧場・根を一切使用していない。
5. Pythonの共有交点分割とVBA出力の座標・接続・材料・境界を照合する。初期/一様/局所細分化で同じbody、水平合力0、鉛直合力−2571.4、力の一次モーメントを確認し、実Excel上下界・根・2%判定を再監査する。未完了・不合格の場は採用しない。

水平以外の指定水位線へ拡張する場合は、水位の各区間と区間切替線も含む圧力の全折れ点を適合化する必要がある。数値浸透FEMの任意圧力場や自由水面の反復解法にはこの水平静水圧の特例を転用しない。既存浸透場を固定して移送する方式は別設計・別検証とする。

現行ソースの接続位置は `versions/G1R19/src/vba/RPX_Mesh.bas` の `RPX_AssignRegions`（末尾でTopology/MapFacesと修復を経てWaterApply）、`RPX_SeepWT.bas` の `RPX_WTHead` mode2、`RPX_Water.bas` の `RPX_WaterApply` である。幾何分割を加える場合は新節点・子三角形を作った後にTopology/MapFacesを再構成し、AssignRegionsの修復再入による二重分割を避ける。水圧は現状でも有効応力の体積力 b-grad(u) として一方向連成されるので、別の水圧合力を加算して二重計上しない。D08Aは固定静水圧モードで水頭3が一定のため、モード2限定の解析評価とメッシュ適合化を導入できる。任意浸透FEM結果の補間は別の既存経路を保持する。
