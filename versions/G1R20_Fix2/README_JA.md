# G1R20 Fix2（2026-10-17）

G1R20 Fix1をレビューし、初期化・メッシュ生成の失敗後の状態と、
水理出力の失敗状態を保存して開き直す経路を修正した版です。
元のG1R20/Fix1のソース・配布ブック・数値証拠は保持します。

## 導入

Releaseの `RPFEM_20261017_G1R20_Fix2.zip` を展開し、`delivery` のXLSMと
`rpfem_native_x64.dll` を同じフォルダーへ置きます。64bit Excel用です。
既存ブックへ移す場合は、`src/vba`（UTF8）または `import`（CP932）の
全63標準モジュールを更新します。既存入力を引き継ぐ場合はSetupを実行せず、
設定プリセットを選択して使います。

## レビューと修正

- Setupが保護シート等で失敗した場合の内部フラグ漏れ、正常初期化後の旧メッシュ・
  結果の有効状態残留、解析中に初期化できる経路を修正します。
- メッシュ生成・解析の失敗でも、元のエラーを記録し、実行状態と
  Excelの取消設定を適切に後始末します。
- 設定プリセットの元の失敗と、結果失効時の保護エラーが重なっても、
  後始末を継続し、最初のエラーを呼出し元へ返します。
- 水理出力・失効処理の開始をブックのカスタムプロパティへ記録します。
  結果シートが保護されて旧収束フラグが残る場合も、保存・再起動後に旧結果を使いません。
  新しい正常出力の完了時に、その出力IDとの対応を記録して回復します。
  この記録がない従来の正常ブックも読み込めます。

変更は `RPX_UI`、`RPX_Control`、`RPX_Water` の3モジュールです。
残る60モジュールとDLLはFix1と同じです。物理式・GAP2%・原q8監査・根幅条件は変更しません。
DLLは同じ `rpfem_native_x64.dll` 1個で、SHA256は
`66da1a21be43cd2b3a3bfbaa9d13aad5fb1fd1960e1bf2507cc4e1cfa9ebe70b` です。
