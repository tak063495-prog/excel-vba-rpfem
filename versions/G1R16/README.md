# G1R16 — 浸透解析の収束判定修正（Issue #6）

2026年10月12日。G1R15（VBA版）とG1R15 DLL2（64bit高速化版）の両方に、浸透解析の収束判定修正を入れた版です。極限解析（上下界・Fs探索・メッシュ最適化・地震）とDLLは変更していません。

## 変更点
- **収束判定**：緩和前の水頭変化量 `dfix`（緩和係数で縮んだ変化量ではない）と、自由節点の正規化された流量釣合い残差 `res` の両方が許容値以下、かつ浸出面の切替なし、の場合のみ収束とする（`RPX_Seep`）。小さい緩和係数で「変化が小さいだけ」の未収束解を収束と誤判定しなくなった。
- **未収束時**：メッセージに反復回数・緩和前変化量・釣合い残差を表示し、連成解析には使わない（`RPX_SeepUI`）。浸透結果シート W1:X3 に `dfix`・`res`・許容値を出力。
- **地下水面からの逆算**：内部の浸透計算が未収束なら残差評価に使わない（`RPX_SeepWT`）。
- G1R15 の `RPX_SeepUI` に残っていたプロジェクト全体コンパイルエラー（関数名 `PX`/`PY` と変数名の衝突。実行時は該当手続きに入るまで顕在化しない）を、DLL2版と同じ `PreviewX`/`PreviewY` への改名で解消。
