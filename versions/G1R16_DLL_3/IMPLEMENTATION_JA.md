# DLL_3の実装内容

## 方針

VBAからDLLをスカラー演算ごとに呼ばず、連続配列を渡してループをDLL内で実行します。VBAは入力・状態・物理監査・求解制御を維持します。変更対象の元の数値ループを残しており、DLLなしでも同じアルゴリズムを使います。

## 対応表

| 対象 | 実装 | 検証 |
|---|---|---|
| 通常NT・DD NT | `rpfem_bulk.h`、`RPX_NativeScaling` | 実VBAの224入力、成功174入力の全成分・DD hi/loがビット一致、50入力の拒否・例外番号一致 |
| NT補正 | `rpx_corrector`、`RPX_NativeCorrector` | 一括演算160組、HSD求解、実FEM場の一致 |
| KKT組立 | `rpx_kkt_init/cones/diagonal/scale` | 元行列・スケールも含む160組のビット一致、堤防全求解 |
| G/G転置 | `rpx_gproduct/gtadd` | オフセット・初期値・係数変更を含む160組、実FEM場の一致 |
| HSD DD原作用素 | `rpx_hoperator` | シフト有無・通常/精密NTを含む160組のDD hi/lo一致、HSD・P06 |
| HSD疎LU | `rpfem_lu.cpp`、`RPX_NativeLU` | 360行列条件、LU因子・ピボット・解の一致、独立残差、異常注入 |
| ソース・保存済みXLSM | `verify_release.py` | 元版の保全、許容した変更モジュールのみ、文書モジュール不変、取込の無損失 |

## 精度と例外

VBAのx87演算順序とDoubleへの格納位置をASMで維持します。平方根はVBAに合わせてSSE2の平方根を使用します。べき乗はVBAの`^`と同じWindowsの旧MSVCRT `pow`を使用します。UCRTの`pow`では、境界に近い点で最下位ビットが異なる例がありました。必要な実行時関数が見つからない場合は起動時にVBAへ切り替わります。

製品経路は浮動小数点制御ワードを変更しません。Pythonからの低水準比較だけ、実Excelで記録した制御ワードをその検証プロセスへ設定しています。

DDの有限性判定はVBAの±1E290を維持し、アンダーフロー、ゼロ除算、オーバーフローを区別します。メモリ不足は7、未知のC++例外は513、取消は18として伝達し、通常のピボット失敗に置き換えません。

## データの再利用

コーンのID・係数・オフセット・KKT位置を配列にまとめます。`RPX_Begin`、`RPX_Compile`、上下界の強度更新、下界キャッシュ復元、準備状態のリセットで無効化します。同じ寸法というだけで再利用せず、実際の状態変更経路に無効化処理を置いています。丸めた浮動小数点キーは使用していません。

HSD LUは一時的なDLLコンテキストで因子を作り、圧縮済み因子をVBA配列へ戻してコンテキストを解放します。因子は両経路で使える形式です。取消・例外でも解放します。直接インデックスと行スタンプの両経路、平衡化、対称/非対称、列順、しきい値ピボット、因子のストリーミングを比較しています。

## 応答と入力確認

処理は区切ってVBAへ戻し、各区切りで`DoEvents`と取消確認を行います。入力表の読取は独立した時計で既存の`HSD_STAGE_SECONDS`に合わせます。既存HSDのモデル・反復状態ガードの時計は変更していません。設定0なら入力確認を各区切りで行います。

## ビルド・試験の再現

リポジトリを取得し、Windowsの64bit Excel、Python環境（pywin32、numpy、scipy、oletools）、C++ Build ToolsとMASMを用意します。既存の許可がある環境でのみExcelソースの取込試験を実行します。試験ツールは設定を自動変更しません。

`native/build.cmd`でDLLをビルドします。`tools/prepare_imports.py`で取込ファイルを生成し、`tools/install.py`で元版から別名コピーを作成して実Excelへ取り込みます。`tests/build_failure_test.cmd`と`tests/build_lu_failure_test.cmd`がC++の異常注入試験です。`tools/test_*`が実VBA比較、HSD、固定Fs FEM、旧Issue、浸透・切替試験です。`tools/run_levee.py`が堤防の実測、`tools/verify_release.py`が原本・保存済みソース・全求解ログの照合です。

ビルド用のVisual Studioパスは実測PCの設定です。他環境ではそのパスを合わせます。試験は専用のExcelインスタンスとコピーしたブックを使い、ユーザーの開いているブックへ作用させません。
