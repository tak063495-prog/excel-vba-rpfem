# G1R20 Fix3（2026-10-17）

G1R20 Fix2をレビューし、浸透結果と入力の対応、保存結果の失効、浸透操作の再開・数式保持、旧モデル読込み、解析的Fsの誤拒否を修正した版です。
過去版の配布物・ソース・数値証拠は変更していません。

## 導入

Releaseの `RPFEM_20261017_G1R20_Fix3.zip` を展開し、`delivery` のXLSMと
`rpfem_native_x64.dll` を同じフォルダーに置きます。64bit Excel用です。
DLLは従来と同じ統合DLL1個です。

既存ブックを更新する場合は、G1R19以降のブックの全63標準モジュールを
`src/vba`（UTF8）または `import`（CP932）で置き換え、さらに
`src/workbook/ThisWorkbook.code.txt` または `import/ThisWorkbook.code.txt` のコードを
**既存のThisWorkbookコードモジュールへ置き換えてください**。標準モジュールとして追加しません。
既存ブックの `RPX_WitnessPayload` クラスは保持してください。配布XLSMには必要なコードが入っています。
既存入力を保持する移行ではSetupを実行せず、設定プリセットを選びます。

## 保存済み結果の扱い

浸透結果は、生成時の入力値・数式・モード・関連形状と結び付けて保存します。
入力が変わった場合は、旧水頭を土の解析へ渡さず、浸透解析の再実行を求めます。
**従来版で生成された浸透結果にはこの対応記録がないため、更新後に浸透解析を再実行してください。**
連成OFFの乾燥解析は、浸透結果の再実行なしで使えます。
目標要素数、積分次数、GAP、ソルバー時間だけの変更では浸透結果を失効させません。

通常解析の保存結果にも入力との対応記録を付けます。開き直す時に入力値が変われば旧表示を失効します。
旧版の対応記録がない通常結果は「入力との対応未確認・再解析してください」と表示し、
その後の入力数式の再計算も監視します。開き直しただけで数値証明を新たに認定する処理ではありません。

数値式、GAP2%、原q8物理監査、根幅の条件を保持しています。
