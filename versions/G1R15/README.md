# G1R15 浸透入力の整理・地下水面入力・水平震度法（地震）

[検証報告](REPORT.md) / [導入・復旧](IMPORT_ROLLBACK_JA.md) / [全体README](../../README.md)

G1R14（定常浸透・間隙水圧の一方向連成）に次を追加する。

1. **浸透入力シートの整理**（`RPX_SeepUI` v8）：上部に「水の与え方」（B3）と必要な入力の案内（H3）、共通設定（γw B4／連成 D4／サクション F4）。旧配置のシートは自動移行。
2. **地下水面から水圧を与える入力**（新規 `RPX_SeepWT`）：B3で4方式から選ぶ。
   | B3の選択肢 | 使う入力 | 水圧 |
   |---|---|---|
   | 水位・水頭の条件から計算する | 透水係数 A:C、水理境界 E:K | 浸透解析（G1R14と同じ） |
   | 地下水面の位置を入力する（斜面に沿った流れを考慮） | 地下水面 M:N（xは増加順） | u = γw·hw·cos²θ |
   | 地下水面の位置を入力する（水は静止とみなす） | 地下水面 M:N | u = γw·hw |
   | 地下水面に合うよう境界の水位を推定する | A:C、E:K（推定値は「?」または「?初期値」）、観測点 P:Q | 逆推定した境界で浸透解析 |
3. **水平震度法**（新規 `RPX_Seismic`）：`設定`シートの15・16行目（浸透とは独立。浸透なしでも使える）。
   | セル | 項目 | 入力 |
   |---|---|---|
   | B15 | 地震：水平震度 kh | 0以上1以下（0＝地震なし、目安0.14〜0.25） |
   | B16 | 地震：慣性力の向き | 右(+x) ／ 左(-x)（斜面が下る谷側を選ぶと危険側） |
   全要素の体積力に水平成分 ±kh·γ（γは全単位体積重量）を加える。自重と同じ荷重区分（固定／比例）に入る。連成ONでは有効応力の体積力（γ−∇u）に加算。結果は`解析結果`H1:H2と`図`M1に表示。
4. **自動実行用の静音スイッチ**：`RPX_SeepSetSilent True` または `RPX_SeepRunSilent()` で浸透関係のMsgBoxを表示せず記録（COM自動実行の停止防止）。

delivery/ は G1R14 の D03N・D07A 配布ブックに導入したもの（kh=0・連成OFFで保存）。examples/ は堤防の連成例題。src/vba/ はUTF-8、import/ はVBEインポート用CP932・CRLF。
