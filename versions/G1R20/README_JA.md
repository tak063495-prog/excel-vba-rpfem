# G1R20 — P06改善経路のVBA実装

P06のPython新規求解でGAP2%以内を再現した手順をVBAへ移す改善版です。
G1R19で見つかったD01/D02の停滞、水位線を横切るメッシュの荷重差、初期化呼出しの修正も含めます。
DLLは引き続き **`rpfem_native_x64.dll` 1個**です。

## 導入と設定

配布ZIPの `delivery` にあるXLSMとDLLを同じフォルダーで使います。配布ブックは標準モデル・未解析の状態で、
「設定」の **「G1R20・改善候補を選択」** を適用して保存します。
既存ブックへソースを移した場合も、この設定を明示的に選んでから解析します。
通常のSetupと従来の2%速度設定は、新しい候補経路を自動では有効にしません。

既存の材料、荷重、A/Nの解析方針、水理入力を確認して解析します。
元の物理制約、q8、GAP2%、根幅条件、失敗候補を採用しない条件は維持しています。
補助問題のsolver statusや補助問題のdualだけで精度達成とは判定しません。

## 実装した改善手順

- 下限候補では全体を均等に細分化し、c=0帯だけに要素が偏る経路を補います。
- 上限候補では、新しく監査した速度場を用いて保護辺を維持したまま辺を組み替えます。
- 新しい形状には原q8の新規求解と根の確認を行い、改善が確認できた候補だけを採用します。
- 上限の元LPが不合格なら、同じFsで補助QPを最大2回求解します。正の仕事量による規準化後も、
  元の物理制約を全て再検査します。補助QPのdualは元問題の根には使いません。
- 根の近傍では試行点と元dual補助問題の順序を調整します。等式乗数だけの線形補正は、
  cone変数を不変に保ち、元dualの全条件を満たしたときだけ採用します。

幾何再現資産に保存場やFsを含めません。Python実験・証拠の詳細は
[再現手順](../../validation/G1R19_python26_dual_linear_repair_20261016/G1R20_RECIPE.md)にあります。
全解析の速度向上率は今回の途中比較から算出していません。
