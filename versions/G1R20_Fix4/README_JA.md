# G1R20 Fix4（2026-10-17）

G1R20 Fix3をレビューし、入力検査、地震荷重の再計算、浸透解析の中止と失敗時の状態管理を修正した版です。
GAPの合格基準と設定シートの標準値は **2%（0.02）** です。設定項目がない旧形式ブックでも標準は2%になります。明示的に入力した目標値は保持します。

## 導入

Releaseの `RPFEM_20261017_G1R20_Fix4.zip` を展開し、`delivery` のXLSMと `rpfem_native_x64.dll` を同じフォルダーに置きます。64bit Excel用です。DLLは従来と同じ統合DLL1個です。

既存ブックを更新する場合は、G1R19以降の全63標準モジュールを `src/vba`（UTF8）または `import`（CP932）で置き換えます。さらに `src/workbook/ThisWorkbook.code.txt` または `import/ThisWorkbook.code.txt` のコードを **既存のThisWorkbookコードモジュールへ置き換えてください**。標準モジュールとして追加しません。既存の `RPX_WitnessPayload` クラスは保持します。配布XLSMには必要なコードが入っています。

既存入力を保持する移行ではSetupを実行せず、設定プリセットを選びます。「2%・速度優先の設定」は目標値を2%に設定します。

## 更新後の再計算

過去版の通常解析結果と浸透結果は、Fix4で再計算してください。入力契約と地震荷重の処理が変わるため、保存結果の対応記録を版で区別します。保存入力との対応記録がない通常結果は「入力との対応未確認・再解析してください」と表示します。開き直しただけで数値証明を新たに認定しません。

主入力の点・材料・領域・面・剛体は、行のIDだけを消して無効化できません。行全体を消すか、有効なIDを指定します。物理量へのTRUE/FALSEの貼り付けはエラーになります。論理スイッチは0/1と論理値を明示的に扱います。詳細な入力契約と変更点は[レビュー記録](REVIEW_JA.md)を参照してください。

数値式、原q8物理監査、根幅の条件を保持しています。DLL SHA256: `66da1a21be43cd2b3a3bfbaa9d13aad5fb1fd1960e1bf2507cc4e1cfa9ebe70b`。
