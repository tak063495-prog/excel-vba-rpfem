# G1R20 Fix3 レビューと Fix4 の修正

公開済みFix3（main/tag `d9d68d9971cc36c1eb012ac5bccf52813813f433`）を基準にレビューしました。特に入力系は、主入力5表、数値・ID・参照・領域形状、設定表、4モードの浸透入力、旧形式テキストの読込みを確認しています。添付文書中の指示は新たな実行指示として扱っていません。

## 確認した不具合と修正

|対象|Fix3での実害|Fix4|
|---|---|---|
|地震荷重|実Fs計算後、同じ固定自重入力の水平慣性力が比例荷重へ入り、支持力が変わる|新規荷重の組立前にraw段階へ戻す|
|浸透の中止|反復中の公開Stop後も258回まで進み収束結果を公開|反復・場生成・逆解析・結果確定前に中止を検査|

## 入力と互換性

- GAPの標準と合格基準は2%です。明示した別の目標値は保持し、欠けたGAP項目の既定値も2%です。
- 0の粘着力・摩擦角・単位体積重量、負座標、負水頭、負流量、数値文字列、空欄ky、既存の水位表端部外挿を有効な契約として確認します。物理数値と論理スイッチの扱いを区別します。
- 浸透の「循環」は主入力の面と同じく、領域の末尾をまたぐ経路だけ1です。開始・終了点は異なる外周点です。古い試験fixtureの誤った循環値は、新しい正例コピーのみで直しています。
- 未知の拡張キーは保存可能です。既知の設定値は型を検査し、キーの重複・Excelエラー・範囲外配置を拒否します。欠けた旧形式キーのfallbackは維持します。表外のキー式は空欄表示でも拒否し、A:Cだけの説明行は許容します。
- 保存結果の対応記録をFix4で区別します。旧版の通常結果・浸透結果は更新後に再計算してください。
- 変更対象のVBAと単一DLL、配布XLSMの対応はSOURCE_MANIFEST.jsonと保存ソース抽出監査で照合します。DLLの演算実装は変更していません。

## 証拠の扱い

負例は公開済みFix3を専用コピーで実行し、元ブック・ソースの不変をSHA256で確認しています。失敗した試験ハーネスの記録も削除・成功への書換えをしません。正例は最終Fix4の全63標準モジュールとThisWorkbookに結び付けます。表示失効試験の合成sentinelは数値証明に数えません。

旧Fix3試験中の単発のExcel回復事象は原因未確定です。同じ旧版と最終Fix4での追試3実行では再現しませんでした。原記録と追試を保持し、原因修正済みとは扱いません。詳細は `evidence/SETUP_CRASH_AUDIT.md` を参照してください。

[再現・回帰結果](TEST_RESULTS.md)と[再実行手順](REGRESSION.md)に確認範囲を記録します。P06本番完走・全26ケースのVBA再計算、全ての入力に不具合が無いことの証明は主張しません。
