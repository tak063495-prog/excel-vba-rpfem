# G1R14 浸透流解析・間隙水圧の一方向連成

[検証報告](REPORT.md) / [導入・復旧](IMPORT_ROLLBACK_JA.md) / [問題と修正の対応](ISSUE_TO_FIX_JA.md) / [手順書](docs/浸透連成_手順書.md) / [全体README](../../README.md)

G1R13のソルバーに、三角形一次要素（T3）の定常浸透流解析と、その間隙水圧を有効応力として上下界Fs探索へ反映する一方向連成、図シートへの自由水面・推定すべり面の重ね描きを追加する。連成スイッチ（浸透入力N19）が0のときは体積力に触れず、G1R13と同じ解析経路になる。

delivery/の2つのXLSMはG1R13のD03N・D07A設定済みブックに本機能を導入したもの（連成OFFで保存、G1R13とFs全桁一致）。examples/は堤防の連成例題。src/vba/はUTF-8編集用、import/はVBEへのファイルインポート用CP932・CRLF。変更は既存2標準モジュールへの各1行と新規3標準モジュール。
