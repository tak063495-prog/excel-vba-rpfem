## 制限
- 浸出点の高さは過小傾向（流量への影響は1%未満）。
- すべり線は辺の階段状経路で、当てはめ半径はやや小さい。
- 水面下の剛体要素には水圧を作用させない。
- 長時間のApplication.Run（COM経由）でDISP_E_EXCEPTIONを観測した例がある。Excelのボタンからの実行を推奨。
- 間隙水圧は定常・一方向。過剰間隙水圧や圧密は対象外。
- 推定すべり面・当てはめ円は上界速度場の可視化で、Fsの根拠ではない。Fsは下界・上界の値で判断する。
- 浸透解析と連成は強度・構成則・数値核を変更しない。浸透結果の精度はメッシュとkr低減（β、krmin）に依存する。
- D03Nの全解析は約2.6時間（9381秒）かかる。複数のExcelを同時に動かさない。
