# G1R14：要求と実装の対応

| 要求 | 実装 |
|---|---|
| 三角形メッシュの浸透流解析 | `RPX_Seep`：T3、材料別kx/ky、RCM並べ替え＋skyline Cholesky |
| 不圧・自由水面 | 固定メッシュ・負圧域のkr低減（exp(β p)、下限krmin）、緩和Picard、浸出面のSignorini切替 |
| 形状定義からの入力 | `RPX_SeepUI`：要素定義の点・領域・面と同じ経路指定で境界（水頭/水位/水位+浸出面/浸出面/流量/不透水）を節点へ自動割当 |
| 一方向連成 | `RPX_Water`：浸透節点水頭を極限解析メッシュへ線形補間、u=γw·max(h−y,0)、要素体積力に−∇u。メッシュ変更ごとに`RPX_AssignRegions`末尾で再計算（冪等） |
| 境界水圧 | 加えない。−∇uの体積積分が外水圧合力を含むため二重計上になる |
| FS探索の荷重配置 | `RPX_TotalReferenceLoads`は不変。λ=1での問題が同一のためFsは不変 |
| 図 | 自由水面、P95基準の速度ジャンプ辺、地表間最短路による連続すべり面、Kasa円弧当てはめ、凡例の図下移動 |
