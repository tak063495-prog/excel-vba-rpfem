rc9a changes relative to read-only vba/ rc8 sources
Changed modules: RPX_Fs, RPX_AccuracyNative, RPX_Audit, RPX_Adapt, RPX_Control.
Fs: preserve original recoverable zero-iterate thin budget error; guarded shape probe; one-shot existing-mechanism test hook.
AccuracyNative: guarded array-shape probes before center/snapshot copy; original dimensions retained.
Audit: preserve allocated/erased prior iterate during FieldGate snapshot and restoration; audit arithmetic/gates unchanged.
Adapt: unchanged original body renamed RunAdaptCore; outer wrapper and one-attempt same-run audited-pair recovery.
Control: one-attempt outer recovery back to normal adaptive output; clear recovered failure flags after diagnostic retention.
Control is the only changed non-ASCII module. This outer output scope requires a handler there; all existing source lines, including every Japanese/CP932 line, are byte-identical.
The exact ASCII additions for Control are listed in its hunks below for hand application. No Japanese line requires manual replacement.
