# G1R20 Fix1（2026-10-17）

G1R20の水理結果キャッシュと設定操作で確認した3件を修正した配布版です。
元のG1R20、過去の数値証拠、配布ZIPはそのまま保持します。

## 導入

Releaseの `RPFEM_20261017_G1R20_Fix1.zip` を展開し、`delivery` のXLSMと
`rpfem_native_x64.dll` を同じフォルダーに置きます。64bit Excelで使います。
ブックはG1R20改善候補の設定を選択した未解析状態です。

既存ブックへ移す場合は `src/vba`（UTF8）または同内容の `import`（CP932）の
63標準モジュールを更新します。G1R19以降のブックでは、Setupによる入力初期化を
行わずに設定プリセットを選択でき、新しい設定行を自動追加します。
材料・領域・荷重・解析政策は引き継いで確認してください。

## 修正内容

1. 浸透結果IDを秒単位の時刻だけに依存させず、同じVBAセッションの出力連番も含めます。
   新しい出力と全モードの入力開始時に水頭・補間キャッシュを破棄します。
   出力の途中や失敗後は古い結果を再利用せず、正常に出力し直した結果だけを読み込みます。
2. 従来の精度・速度プリセットにも例外時の後始末を追加しました。
   内部書込みフラグを元に戻し、通常操作で部分変更があれば旧結果を無効化して元のエラーを返します。
3. プリセットが値を設定する前に、G1R20で追加した7設定を作成します。
   旧ブックへのソース更新直後に設定不足で停止する経路を修正しました。

変更は `RPX_Water`、`RPX_Seep`、`RPX_SeepUI`、`RPX_UI` の4モジュールです。
残る59モジュール、物理式、GAP2%、原q8監査、根幅条件はG1R20と同じです。
DLLもG1R20と同一の1個で、SHA256は
`66da1a21be43cd2b3a3bfbaa9d13aad5fb1fd1960e1bf2507cc4e1cfa9ebe70b` です。
