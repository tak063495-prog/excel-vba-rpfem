The final three-module source was tested with the four accuracy fixes in a seven-module D08 cold run: 883.952 s, lower 1.3015815066522918, upper 1.3260274687490892, symmetric GAP 1.8607001517844293%, both original q8 audits and own roots passed. The static tests alone are not numerical evidence. Apply all three modules together to a copy of the full workbook. Other modules retain their current integration-owned versions.

## Eligible model and fallback

The special path requires coupling ON, suction OFF, prescribed mode 2, a finite positive water unit weight, and at least two distinct water-table x coordinates whose y values are exactly equal. It also requires a completed mode-2 result with a calculation ID and every stored head exactly equal to the current table level. Rigid regions/elements are excluded. Arbitrary FEM seepage results, sloping tables, failed/incomplete results, results with different heads, other modes and incomplete input keep the existing WaterApply path. A historical mode-2 result with the same constant head describes the same global prescribed pressure; the eligibility test does not claim that its old mesh or calculation ID proves freshness relative to every past input edit.

The mesh hook runs after the raw region assignment and initial Topology/MapFaces, before the existing corner/fan/load repairs. Strictly crossing triangles are clipped at the level using one shared intersection per original edge; an existing on-line node is reused. Children retain their parent material and raw body arrays. A quad uses the better minimum triangle quality of its two diagonals. Before committing, the code checks positive children, parent containment, parent area and first moments. After Topology/MapFaces it checks every literal six-field exterior boundary record and that no triangle crosses the level. Ordinary rejection may restore the original arrays/dictionaries and verified topology/boundaries before falling back. A separate restoration handler records errors in array restoration, Topology, MapFaces or boundary verification. Any restoration failure aborts with `WATER_COMMON_ROLLBACK_FAILED`, separately identifying original and restore number/source/message, and invalidates mesh/results/prepared state/caches/roots. Explicit cancellation keeps error 18 even when restoration also fails. Input mismatch and cancellation always propagate instead of becoming a fallback.

Waterline edges enter `RConstraints` solely to protect geometry during refinement, relocation or remeshing. Already-conforming waterline edges are protected too. The code adds no `DFaces`, material interface, physical exposed face, velocity glue, or mechanical waterline restraint. Existing material interfaces and exterior constraints are split using the same shared node IDs.

On an eligible conforming mesh, WaterApply uses the exact derivative of the existing prescribed pressure `u=gamma_w*max(level-y,0)`: `-grad(u)=(0,gamma_w)` below and zero above. It keeps the existing gravity/load-phase/seismic handling and adds no separate external water force. Otherwise the existing interpolated P1-pressure gradient is used. WaterCommon eligibility alone never certifies a field or a bound.

Geometry or constraint changes clear the prepared solver, lower cache and Fs brackets. Exact model identity already includes mesh coordinates/connectivity, constraints and body arrays. Input epoch is not artificially advanced because the original input remains the same. Historical nonconforming fields/roots must not be certified on this mesh: only new original-q8 field audits and own-mesh root closure may establish bounds. The physical and root tolerances, quadrature and 2% acceptance policy are unchanged.

## Bound water source during an analysis

The original input guard watched only geometry, materials and settings. The added `RPX_Guard` hooks bind eligible prescribed-water input at the standard `RPX_InputBegin` epoch, assert it at every standard `RPX_AssertInputs` (including solver stages and final `result_commit`), and clear it at `RPX_InputEnd` and a new begin. Input eligibility at begin does not depend on stale rigid/mesh globals from a previous run; the actual mesh still must pass the existing soil-only qualification.

The snapshot records cell values and formulas with original Variant types, length-delimited strings and raw IEEE754 double hex. It covers layout/mode labels, coupling, suction, gamma, the entire water table, convergence/calculation ID/mode/count headers, result node coordinates/heads and result triangles. Exact bit/type changes, missing source sheets and epoch changes abort with `WATER_COMMON_SOURCE_CHANGED`, cancel the analysis, clear prepared programs/caches/roots and mark mesh/results noncurrent. The changed source cannot silently select the old P1 load after binding. Once exact common-water loading has been applied in an analysis, later loss of conformity/eligibility also aborts instead of reverting to P1. The current result cache is reloaded for a new eligible run even when a result ID was reused.

An analysis that was ineligible at begin cannot engage the common-water branch later in that same run. Its original legacy fallback remains unchanged. Mesh previews outside an active input scope may use the current source without retaining a run snapshot. Dry models retain their numerical path and no water result snapshot is captured for them.

## Static verification

```powershell

```

All 21 solver-free tests pass: 7 geometry tests, 8 source-binding contract/static-hook tests and 6 rollback-failure contract/static-handler tests. A scalar-double translation of the proposed VBA clipping code is compared with the separate water Python implementation. On the recorded D08 coarse domain, all coordinates, connectivity, material IDs and parent IDs agree: 214 to 276 triangles, 130 to 162 nodes, 32 shared intersections. Each child remains in its parent; area is 158. The six literal exterior condition fields agree with a fresh map from the canonical D08 input. A second split is unchanged. Tests cover a shared material interface, existing on-line vertex, no crossing, large translated coordinates and rejected invalid geometry without changing source arrays.

The D08 exact body has horizontal force 0 and vertical force -2571.4. Force and first moments agree after uniform refinement to 1104 triangles and an independent local centroid refinement. The exact piecewise derivative agrees with nodal P1 differentiation to less than 1e-14 in these tests. The saved fixture is `results/D08A_expected_common_geometry.npz`; `results/STATIC_GEOMETRY_COMPARISON.json` records input/reference/fixture hashes and measured errors.

The source tests check the required typed-state semantics, every changed water-source component, epoch/new-run/preview behavior, standard lifecycle hooks and propagation outside eligibility fallback. These checks validate the algorithm and model correspondence. They do not execute the VBA arrays, exception handler, Excel input readers or cancellation code. `SOURCE_MANIFEST.json` identifies the three base modules, candidate/import hashes, canonical input and independent reference. No Python file is a workbook runtime dependency.

The rollback checks cover successful verified restoration, failure in restoration, distinct original/restore errors, cancellation in either phase, simultaneous original cancellation plus restore failure, and input mismatch propagation. Fault hooks use only the existing explicitly armed `RPX_TestHook` mechanism; its production default remains disabled. Actual exception-handler behavior still requires the following VBA probes.
