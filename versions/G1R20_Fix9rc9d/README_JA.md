# G1R20 Fix9 rc9d（候補）

rc9b のあとの候補版です。rc9c と rc9d の変更が入っています。コードは Codex が書き、こちらで確認しました。

## rc9d で変わったこと（rc9c との違い）

- `ACCURACY_DLL_UPPER_EQUILIBRATE` の既定を **1 から 0** に戻しました（`RPX_AccuracyNative.bas` のコード既定 1 行、`RPX_UI.bas` の設定行とプリセット 3 行。ASCII 4 行のみ）。1 は設定行で引き続き使えます。
- 理由：P02A_THIN で equilibrate=1 だと GAP 0.531%（目標 0.500% 未達）、0 だと 0.457% で PASS。分岐は適応サイクル 1 から始まります。

## rc9c で変わったこと（rc9b との違い）

- 深夜 0 時をまたいでも経過時間が正しくなるよう、単調な時計 `RPX_ClockModule`（Win64 では GetTickCount64、それ以外は日付の戻りを補正した Timer）を追加し、経過時間に使う `Timer` をすべて置き換えました。
- rc9b P06N の `thin_layer_step seconds=-84046` はこれが原因でした。時間保護の判定はもともと正しく動いていたことをログで確認しています（表示だけの不具合）。
- 詳しくは `versions/G1R20_Fix9rc9c/TEST_RESULTS.md` と `codex/` にあります。
